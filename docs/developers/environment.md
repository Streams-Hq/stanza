# Environment variables

Every value the app and indexer read, with testnet defaults.

## Frontend — `apps/web/.env.local`

`NEXT_PUBLIC_*` values are **inlined at build time**. Set them in your hosting
platform before building, and redeploy after changing them.

| Variable | Required | Testnet default | Purpose |
| --- | --- | --- | --- |
| `NEXT_PUBLIC_STELLAR_NETWORK_PASSPHRASE` | yes | `Test SDF Network ; September 2015` | Network the wallet signs for |
| `NEXT_PUBLIC_SOROBAN_RPC_URL` | yes | `https://soroban-testnet.stellar.org` | Soroban RPC endpoint |
| `NEXT_PUBLIC_STANZA_CONTRACT_ID` | yes | `CDGIYCP56ZAC5ZVTJVHJQ5H7OLZSCDU3DFA77VWXT74N47MW6ZBV4FDP` | Deployed `stanza-subscriptions` contract |
| `NEXT_PUBLIC_INDEXER_URL` | no | `http://localhost:3001` | Indexer REST base URL |
| `NEXT_PUBLIC_DEFAULT_TOKEN_ADDRESS` | no | native XLM SAC `CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC` | Token pre-filled in the plan form |
| `NEXT_PUBLIC_TOKEN_DECIMALS` | no | `7` | Display precision for amounts |
| `NEXT_PUBLIC_EXPLORER_BASE` | no | `https://stellar.expert/explorer/testnet` | Explorer links for transactions and the contract |

!!! warning "The XLM SAC is not the Stanza contract"
    `CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC` is the native XLM
    Stellar Asset Contract — the *asset* being billed. The Stanza contract goes in
    `NEXT_PUBLIC_STANZA_CONTRACT_ID`.

## Indexer — `indexer/.env`

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| `PORT` | no | `3001` | REST API port |
| `SOROBAN_RPC_URL` | yes | `https://soroban-testnet.stellar.org` | Soroban RPC endpoint |
| `STELLAR_NETWORK_PASSPHRASE` | yes | `Test SDF Network ; September 2015` | Network passphrase |
| `STANZA_CONTRACT_ID` | yes | *(the deployed id)* | Contract to index |
| `START_LEDGER` | no | `0` | First ledger to scan with no stored cursor |
| `DB_PATH` | no | `stanza.sqlite` | SQLite file path |

`STANZA_CONTRACT_ID` must match `NEXT_PUBLIC_STANZA_CONTRACT_ID` for the same
network. If it is empty, the indexer waits and re-reads the environment each poll
instead of scanning the wrong contract.

## Deployment output

`pnpm deploy:testnet` prints and writes:

```text
STANZA_CONTRACT_ID=C...
NEXT_PUBLIC_STANZA_CONTRACT_ID=C...
```

and stores the full record in [`deployments/testnet.json`](https://github.com/stanza-labs/stanza/blob/main/deployments/testnet.json)
(contract id, wasm hash, deployer, RPC URL, timestamp).
